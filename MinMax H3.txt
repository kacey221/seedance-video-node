MiniMax Design介绍 
MiniMax Design 是由 AI Agent 驱动的商业内容生产平台，将多模态模型能力转化为真实可用的生产力。

Design的核心优势，是理解、拆解并执行商业内容生产任务。
用户只需表达创作目标，Design Agent 就能规划任务、扩展 Prompt、选择合适的 Skill 与工具、调用适配模型，并组织素材、持续修改，推动内容从想法走向交付。

🤖Agent基础链路
理解需求 → 拆解任务 → 选择 Skill 与工具 → 调用模型 → 生成与修改 → 完成交付
📈优势场景
尤其适合短、快、模板化和批量化的商业内容生产，包括广告投放、电商素材、品牌宣传、KOC 内容、短视频、Motion Graphic、3D 资产及影视后期等
🧑‍🎨适用人群
面向广告、品牌、电商和内容运营团队，以及视频创作者、设计师、影视从业者、AI 创作者与开放工作流开发者。

1.2 基础创作过程
用户可以通过四种方式开始：
方法一：直接描述目标
适合已经知道自己想做什么的用户。
为一款无线耳机制作一条15秒竖屏广告，突出轻便和降噪，风格简洁、有科技感。


	
方法二：从 Skill 开始
适合有明确任务，但不知道具体流程的用户。
什么是Skill ？
Skill 不是单个功能，而是针对具体任务组织好的执行流程。
它可以是行业规范与标准，比如短剧制作的完整流水线：剧本 → 分镜 → 角色与场景 → 图生视频 → 配音配乐 → 合成输出。也可以是创作偏好与审美准则，比如"品牌视觉风格偏简洁、少文字"。
•如何使用Skill？
1.方法一：在广场直接试用
 在 Skill 广场或我的技能中，选中想用的 Skill，点击「去对话中试试」，就能直接调用。

Skill广场界面
	
下载前，可点击查看详情
2.方法二：/ 快捷键调用
 在对话框输入 /，选择想要的 Skill，明确告诉 Agent 你要用哪个。选定后，跟着 Skill 的引导一步步操作就好了。
3.方法三：直接和Agent 询问匹配
例如，你可以在对话框：“我要做一个批量 KOC 美食吃播视频，请帮我调用相应的 skill 完成。”Agent 就会调用「批量 KOC 」的技能。
4.方法三：Agent 自动调用
 对于已经开启的 Skill，Agent 会根据你的对话内容自动判断该用哪个。
比如你开启了「海报设计」这个 Skill，当任务涉及到制作海报和图示能力时，Agent 会自动调用它，直接写出高质量的提示词——不需要你手动触发。
💡 所有下载保存的 Skill 都会存在「我的工具」里，用 / 时也能直接看到全部。

[CleanMate-X8Pro-养猫家庭种草-猫砂修正版.mp4]
1.提出需求
目标：制作扫地机器人种草视频  核心卖点：宠物毛发与猫砂碎屑清洁
视频时长：15 秒  内容形式：真人口播＋实测  目标家庭：养猫家庭
2.Agent 确认信息
产品：CleanMate X8 Pro；发布平台：小红书；画面比例：9:16；出镜人物：年轻短发女性；博主人设：松弛日常记录博主；输入素材：产品图片、视频、官方卖点与参数资料
3.核对产品卖点
Agent 读取产品资料，确认可用于视频的官方信息，包括吸力、防缠毛、碎屑处理、自动集尘与避障等能力。
内容原则：仅使用有依据的产品卖点，不虚构或夸大清洁效果。
4.确定创意方向
开场主题：猫砂碎屑问题
内容结构：前 3 秒呈现猫砂碎屑痛点—博主口播引出产品—实测清理猫毛与猫砂—展示清扫前后效果—结尾总结养猫家庭使用体验
5.锁定人物形象
人物方向：年轻、短发、韩系
内容气质：自然、松弛、生活化
生成素材：人物身份锚图
确认结果：后续镜头统一使用该人物形象
6.生成脚本与分镜
Agent 基于已确认的产品卖点、人物形象和开场方向，生成完整口播文案与连续分镜。用户确认内容后，再进入视频生成与修改环节。

🛍️活人感「KOC 社媒投流广告」（中英）
通用提示词模板：
为一款面向【目标市场/目标人群】的【产品】制作一条【时长与画幅】广告，突出【使用场景、核心卖点与促销信息】，整体呈现【博主人设/视觉风格】，用于【投放渠道】。请基于我提供的产品图与官方信息生成脚本、分镜和成片，并在需要时向我确认真实使用方式。

关键步骤	Agent产出画布截图 / 成品
提出需求
香薰精油类 欧美博主生活测评的15s小广告 黑五大促前电商广告 时尚领域博主的品味推荐，英文
	
案例：欧美时尚博主香薰精油 Black Friday 广告
1｜提出需求

Design 根据用户设定生成风格参考图，统一冷色调、废墟环境、角色服装、光影氛围和动作美术方向。这样上下两段即使分开生成，也能保持同一套 PV 视觉语言。
4｜生成关键画面
Design 继续生成多张关键帧，包括远景对峙、角色登场、冲刺交锋、武器特写、能量爆发、背对背定格等画面。每张图都对应具体镜头，作为两段视频生成的视觉锚点。
5｜分段生成视频
Agent 将分镜和关键帧拆成两次视频生成任务：第一段生成“登场与初次交锋”，第二段生成“战斗升级与结尾定格”。分段生成可以提高长视频稳定性，也方便用户单独修改某一段的节奏、动作或镜头。
6｜衔接与调整
两段视频生成后，Design 继续处理转场、节奏、画面一致性和结尾收束。如果某一段动作不够强、角色位置不统一或特效过弱，用户可以只修改对应段落，不必重做整条视频。
7｜最终交付
最终输出一条 30 秒风格化动画 PV，可用于游戏概念展示、角色预告、IP 氛围片或创意短片。该案例展示了 Design 在创意内容中的能力：从一句故事设定出发，自动完成脚本、分镜、风格统一、关键帧生成、分段视频生成和最终成片。	


🏃H3美学应用「特效包装- AR短片为例」
为一个【实验视觉短片/风格化短片/品牌概念片】制作一条【时长与画幅】的实验性影像作品，整体呈现【视觉风格】，以【人物动态/场景氛围/图形节奏】为主线，包含【开场方式/转场逻辑/情绪氛围】。请先解析我上传的参考视频和人物图，锁定人物形象、视觉结构和节奏卡点，再帮我拆解脚本和分镜，生成关键锚定图；分段生成视频时保持人物、场景和风格一致，最后拼接成完整成片，并统一配乐与节奏卡点。

关键步骤	Agent产出画布截图/成品
用户上传一段参考实验短片视频和一张人物图，提出核心需求：基于参考视频的视觉风格，重新生成一支实验视觉短片，16:9 横屏，保留横向奔跑人物作为视觉主线，人物形象根据上传的人物图重新生成，文案由 Agent 生成。	
[AR动画1.mp4]

案例主题
制作一支约 1 分多钟的实验视觉短片，采用实拍街景 + 人物动态 + 图形风格切换的融合风格，以横向奔跑人物为主线，通过画面缩入黑底、人物剪影作为动态遮罩、快节奏图形切换和音乐卡点，营造强烈的视觉冲击与节奏感。
1.任务拆解与参数确认
Agent 自动加载实验短片生成技能，先解析参考视频的视觉结构（开场街景、人物动态方向、转场方式、图形风格、节奏卡点），再结合人物图提取人物特征（身份、服装款式、体态），一次性确认关键制作参数：16:9 画幅、人物形象锁定、图形风格方向、英文文案由 Agent 生成，并整理出完整的制作简报和叙事方向。
2.文案生成与锚定图产出
Agent 根据参考视频的视觉调性和节奏特征，生成 3 个实验风英文短文案候选，用户选择推荐文案后，Agent 基于上传的人物图重新生成人物形象，并产出三张 16:9 独立锚定照片（开场街景人物构图、黑底剪影动态构图、结尾图形文案构图），避免四宫格拼贴干扰视频生成。
3.多技能Skill协同：TVC、品牌与资产生成
在短片制作过程中，Agent 根据需求动态调用多个专业 Skill 协同工作：
TVC 技能：用于规划短片的整体叙事节奏和镜头语言，确保各段节拍分配合理、转场流畅。
品牌技能：负责锁定图形风格模板、品牌图形规范和视觉调性，保证成片风格与品牌调性一致。
Film Assets 技能：根据用户上传的人物图，自动切换至资产生成模式，用图一锁定人物身份、图二锁定服装款式，生成正面/侧面/背面三视图，确保人物形象在整支短片中保持一致。
4.分段生成与拼接成片
整支短片并非单次生成，而是按分镜拆分为多个独立片段分别生成，最终拼接成完整成片：
Agent 先生成精确节拍与文字分镜表，明确每个时间节点的画面、人物运动方式、图形切换时机和转场节奏。
用户确认后，按分镜逐段调用 MiniMax-H3 生成各段视频，每段使用对应的锚定照片作为参考图。
所有片段生成完毕后，按分镜顺序拼接成完整短片，总时长约 1 分多钟，并统一配乐和节奏卡点。
5.提示词优化与风险规避
当用户提出包含"蛛丝""模拟参考视频运镜"等高风险表述的复杂提示词时，Agent 自动加载视频提示词优化技能，识别出 IP 联想风险、版权复刻风险和动作过载风险，并给出安全改写方案：将"蛛丝"替换为"细白色弹力绳"，将"模拟参考视频运镜"替换为"快速横向跟拍、卡点闪切、平面空间穿梭感"，同时将复杂动作拆分为多段独立生成，显著提升成功率。
6.最终产出
输出一条约 1 分多钟的 16:9 横屏实验视觉短片，风格为实拍街景与图形动画融合——以真实街景开场，人物横向奔跑，画面随后缩入黑底空间，人物剪影作为动态遮罩与抽象图形、品牌色块不断切换，形成强烈的视觉冲击和节奏感，附带原生科技配乐效果。

•进阶：自定义Skill

•或直接告诉 Agent「把当前对话总结成 Skill」，它会自动把这套流程打包保存下来。
	方式三：修改已有 Skill 
•在使用某个 Skill 的过程中，如果遇到不满意的地方，随时可以叫停、调整细节。改完觉得不错，告诉 Agent「保存为我自己的 Skill」，下次就能直接用改好的版本了。

	方式四：上传已有资料来创建
•手头有经验文档、笔记，或者其他 SKILL.md 文件，直接上传给 Agent，描述你想要的 Skill 是什么，它会根据资料帮你生成。

基础介绍
•MiniMax Design 基于 MiniMax H3 开源模型，开放本地部署与 ComfyUI 工作流能力。用户可以在自己的设备上运行部分视频生成流程，并将 H3 的视频生成能力接入 Design 的画布与 Agent 创作流程中。
•Design 进一步把 H3 的模型能力封装成可下载、可运行、可调整的精选工作流，让用户不必从零搭建复杂的 ComfyUI 流程，也能更低成本地开始本地创作。
•目前，Design 已配备多套「官方精选工作流」，覆盖文生视频、首尾帧、多参考、超清、扩写、人像增强等不同能力。你可以根据电脑配置、创作需求和成本偏好，选择轻量版、满血版，或带有官方超清、扩写等增强能力的版本。轻量版更适合快速体验和普通设备运行；满血版效果更完整，但对显存、内存和本地存储要求更高。
💡 部分工作流可以完全在本地运行，不产生额外生成消耗；如果使用官方超清、扩写等云端服务，则可能产生相应积分消耗。下载工作流时，系统会根据本机配置给出推荐方案。推荐结果仅供参考，不代表其他版本完全无法运行，只是流畅度、稳定性和最终效果可能会受到影响。
